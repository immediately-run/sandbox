## Load-bearing-but-legacy-looking surface (KEEP — do not delete)

These look like CodeSandbox/Sandpack cruft but are **contract/runtime glue** the
app↔host **sandpack iframe protocol** depends on (core_concepts §1). Recorded here so
the dim-4 sweep does not mis-flag them and a future reviewer does not "clean them up".

### `targetOrigin='*'` + `data.codesandbox` handshake — HOST_ORIGIN_HARDENING §2.4

- **Paths:** `src/protocol/iframe.ts` — `_postMessage` (`window.parent.postMessage(message,'*')`, ~line 150); inbound guard `if (!data || !data.codesandbox) return;` (~line 93); outbound stamp `codesandbox: true` (~line 158); `register-frame` handled *before* the guard (~line 33).
- **Why correct, not a hole:** this frame runs at an **opaque origin** (no
  `allow-same-origin`), so there is no concrete origin to name — `targetOrigin='*'`
  is mandated by HOST_ORIGIN_HARDENING §2.4's **MessagePort identity rule**: identity
  is established by the source window + the transferred `MessagePort` handshake, not by
  an origin string. The `data.codesandbox` flag is the **wire discriminator** of the
  sandpack iframe protocol (stamped on every message both directions), not branding.
  An inline comment to this effect was added at `_postMessage` in this pass.

### `__csb_runtimes/` runtime path — sandpack module runtime

- **Path:** `src/bundler/bundler.ts:~362` (`/node_modules/__csb_runtimes/${id}.js`).
- **Why keep:** stable namespace where module runtimes (react-refresh, etc.) are
  registered; part of the inherited Sandpack module-runtime contract.

### `$csb$eval` eval wrapper — sandpack module-eval internal

- **Path:** `src/bundler/module/eval.ts:~63` (`(function $csb$eval(<globals>) { … })`).
- **Why keep:** the controlled-scope IIFE that injects `require`/`module`/`exports`/
  globals for each evaluated module; a Sandpack module-runtime internal.

### `CDN_ROOT` dependency-resolution CDN — PRETRANSPILED §0/§5.4

- **Path:** `src/bundler/module-registry/module-cdn.ts:7` (`https://sandpack-cdn-staging.blazingly.io/`).
- **Why keep (Q3=yes, load-bearing):** used on **every compile** via `fetchManifest`
  (`/dep_tree/…`) and `fetchModule` (`/package/…`); PRETRANSPILED §0/§5.4 reference
  this `/dep_tree/` endpoint. **Open verify item (not a deprecation):** it is a
  CodeSandbox-lineage host (`blazingly.io`) pointing at a **`-staging`** subdomain —
  confirm it is the intended **prod** CDN and that it is on the HOST_ORIGIN_HARDENING
  §2.1 `connect-src` allowlist + the parent immutable-fetch allowlist. Annotated inline
  in this pass. → DOCS DELTA (verify, don't assume).
